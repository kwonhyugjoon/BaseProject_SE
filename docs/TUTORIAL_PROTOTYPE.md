# 튜토리얼 프로토타입: 지도 밖의 첫 걸음

작성일: 2026-09-09  
상태: 최초 버전 사용자 실행 확인 완료. 렌더링·월드 확장 버전은 빌드·실행 및 시각 확인 대기  
관련 기준: [초기 기획서](INITIAL_GAME_PLAN.md), [게임 개발 기준](GAME_DESIGN.md)

## 목표와 범위

작은 마을에서 출발해 주변 숲과 호수를 돌아오는 약 5분의 싱글플레이 튜토리얼이다. WASD 이동, 근접 상호작용, 인물과 환경의 단서를 연결하는 탐험, 선택에 따른 세계 반응을 확인한다.

갈대여울·등장인물·퀘스트 세부 명칭과 2.5D 표현 방식은 이번 프로토타입의 작업용 설정이다. 본편의 이름과 최종 아트·카메라 방식을 확정하지 않는다.

C++ / OpenGL을 유지한다. 2D 다각형을 월드 좌표에서 쿼터뷰로 투영하고 물체의 발 위치를 기준으로 앞뒤 순서를 정렬하는 방식이다. 삼각형 배치 렌더링, 한국어 UI, 물결·불빛·연기·부유 입자 등의 실시간 표현을 사용한다. 외부 이미지나 신규 라이브러리는 추가하지 않았다.

## 공간 구성

월드는 304 × 264 작업용 단위로, 직전 152 × 132 대비 가로·세로 각각 2배, 면적 4배다. 건물 15채와 마을 광장, 숲, 호수, 동쪽 농가·초원·야영지·폐허를 연결한다. 기존 필수 퀘스트 지점은 옮기지 않았다. 지도의 방향은 월드 기준이고 실제 화면은 쿼터뷰다.

| 장소 | 좌표 | 역할 |
|---|---|---|
| 마을 출발 | (18, 50) | 안전한 시작과 이동 학습 |
| 촌장 엘린 | (20, 45) | 의뢰 수락과 마지막 보고 |
| 숲지기 로안 | (12, 29) | 숲 탐험 안내 |
| 오래된 표석 | (21, 11) | 첫 환경 조사, 고대 통로의 흔적 |
| 버려진 야영지 | (34, 13) | 지도 조각 발견 |
| 어부 미라 | (45, 43) | 미지의 존재에 관한 다른 관점 |
| 호수 서쪽 제단 | (43, 24) | 두 가지 선택과 즉각적인 세계 변화 |
| 호수 | 중심 (57, 28) | 탐험의 목적지, 진입 불가 수면 |

총 38명의 대화 가능한 주민·여행자가 있다. 2026-09-30에 20명을 추가했다. 엘린·로안·미라 3명은 기존 필수 퀘스트 위치를 유지한다. 나머지 35명은 순찰·작업·왕복 여행·배회 성향을 조합하여 이동과 휴식을 반복한다. 주민별 이동 방향·속도·대기 시간이 다르고, 작업 단계에는 손의 도구가 움직인다. 가까운 플레이어를 바라보며 멈추고 대화 중에는 이동하지 않는다. 건물·호수·나무 충돌을 확인하며 길이 막히면 방향을 바꾸거나 다음 단계로 넘어간다. 플레이어에서 60 단위보다 먼 주민은 갱신을 쉬고, 재시작 시 초기 위치와 행동 상태로 돌아간다.

확장 지역에는 동쪽·북동쪽 길과 주민 쉼터를 추가했다. 지면은 8×8 월드 단위 Actor로 묶어 1,254개만 사용한다. 이전 지면 Actor 5,016개보다 적다. 나무 후보는 면적에 맞춰 4,400개로 늘리되 도로·주민 출발점·집 주변에는 배치하지 않는다. 축소 미니맵은 전체 지역이 기존 패널에 들어가도록 맞춘다.

## 약 5분의 진행 설계

| 목표 구간 | 시간 예산 | 내용 |
|---|---|---|
| 0:00–0:45 | 45초 | 시작 안내, WASD 이동, 엘린과 의뢰 대화 |
| 0:45–1:35 | 50초 | 마을 구경과 선택 대화, 숲지기 방문 |
| 1:35–2:40 | 65초 | 숲길 탐험, 표석과 야영지 조사 |
| 2:40–3:30 | 50초 | 호수 접근, 미라의 이야기 듣기 |
| 3:30–4:15 | 45초 | 제단 조사, 미지의 목소리에 대한 선택 |
| 4:15–5:00 | 45초 | 달라진 호수 확인, 귀환과 엘린에게 보고 |

시간은 이동·대화 읽기·짧은 구경을 포함한 설계 예산이다. 이동 속도는 카메라 이동을 제외한 화면 투영 기준 84픽셀/초로, 가로·세로·대각선 입력의 길이를 먼저 정규화한다. 쿼터뷰 투영 때문에 월드 좌표에서의 속도는 방향에 따라 다르므로 월드 거리만으로 이동 시간을 계산하지 않는다. 강제 대기나 5분 제한은 없으며 대화를 빠르게 넘기면 훨씬 짧아질 수 있다. 확장 지역은 선택 탐험 구간이므로 전체 탐험은 5분을 넘을 수 있다. 기존 필수 퀘스트의 실제 4–6분 내외 도달 여부는 플레이로 확인하고 이동 속도·대화량·동선을 조정한다.

## 퀘스트 상태와 완료 조건

시작 안내 → 엘린 → 로안 → 표석 → 지도 조각 → 미라 → 제단 선택 → 엘린에게 보고 → 완료.

각 필수 단계는 대화의 마지막 페이지를 닫았을 때 진행한다. 앞선 단계를 건너뛰고 장소에 방문해도 후속 퀘스트가 임의로 완료되지 않는다. 완료 후에도 자유롭게 이동하고 주민 대화를 들을 수 있다.

| 제단 선택 | 즉시 변화 | 귀환 후 반응 |
|---|---|---|
| 1: 종을 울려 응답 | 호수에 빛나는 점들이 늘어남 | 엘린·미라·아이가 연결과 빛을 언급 |
| 2: 종을 감싸 잠재움 | 신비한 불빛이 사라지고 제단의 종을 덮음 | 엘린·미라·아이가 고요해진 호수를 언급 |

선택 이력은 HUD에 표시하고 현재 플레이 세션 동안 유지한다. 재시작 또는 앱 종료 후에는 초기화된다. 디스크 저장은 이번 범위에 포함하지 않는다.

## 조작

| 키 | 동작 |
|---|---|
| W / A / S / D | 화면의 위 / 왼쪽 / 아래 / 오른쪽으로 이동 |
| E | 2.5단위 이내의 가장 가까운 주민·단서와 상호작용, 대화 다음 페이지 |
| Space | 대화 다음 페이지 |
| 1 / 2 | 제단 선택창에서 선택 확정 |
| M | 전체 지도 열기·닫기 |
| P | 후처리 켜기·끄기 비교 |
| Esc | 일시정지·계속 |
| R | 일시정지 중 튜토리얼 처음부터 다시 시작 |
| Q | 일시정지 중 종료 |

대화·선택·전체 지도·일시정지 중에는 이동하지 않는다. 목표는 HUD와 지도의 노란 점으로 표시한다. 물, 건물, 나무 줄기, 월드 경계에는 이동 충돌을 적용한다. 가까운 나무가 캐릭터를 가리면 잎을 반투명하게 표시한다.

## 렌더링 분위기

- 마을: 돌 포장과 흙길, 석조 기단·얼룩진 회벽·목재 골조·지붕 무늬. 문·창문·덧문은 벽면 방향으로 투영하며 처마·용마루·굴뚝과 퍼지는 연기를 표현한다. 창문은 HDR 발광색을 사용한다.
- 숲: 다섯 층의 가지와 잎을 가진 침엽수, 가지·뿌리와 여러 잎 덩어리로 구성한 활엽수. 잎 무늬와 바람 흔들림을 적용하며 플레이어를 가릴 때 층별 투명도를 낮춘다. 길 가장자리에는 꽃과 부유 입자가 있다.
- 호수: 가장자리 거리로 근사한 수심 색, 서로 다른 크기의 불규칙한 잔물결·햇빛 반짝임·얕은 물의 빛무늬·포말. 물가에는 돌과 여러 줄기의 갈대를 배치한다. 물 위 미지의 빛은 기존 선택 결과에 따라 달라진다. 마을과 야영지에는 불꽃·불티·연기·주변 발광 효과가 있다.
- 캐릭터: 머리·얼굴·상의·벨트·가방·팔다리·장화를 세분화한 48×64 스프라이트. 4방향 각각 8프레임 걷기와 정지 포즈를 사용하고, 의상 마스크로 인물별 색상을 적용한다.
- UI: 어두운 반투명 패널, 금색 목표, 한국어 대화와 지도.

재질과 스프라이트 아틀라스는 코드에서 생성한다. 외부 아트 파일은 필요하지 않으며 최종 아트 에셋이나 PBR 재질로 확정된 것은 아니다. 이번 확장의 실제 시각 결과는 빌드 후 확인해야 한다.

### 렌더링 단계

1. 지면 무늬는 월드 좌표에, 건물 벽·지붕과 나뭇잎 무늬는 각 표면의 좌표에 고정한다. 회벽·잎을 포함한 재질 셰이더를 적용한다.
2. 물체 높이와 한 방향의 광원을 기준으로 부드러운 투영 그림자와 접촉 그림자를 지면에 먼저 그린다.
3. 건물·나무·인물·짐승·불꽃을 깊이순으로 그려 HDR 프레임버퍼에 담는다.
4. 대비 기반 가장자리 완화, 밝은 부분의 블룸, 따뜻한 색 보정과 약한 비네트를 적용한다.
5. UI와 한국어 대화는 후처리 이후에 별도로 그린다.

그림자는 2.5D에 맞춘 근사 투영 방식이며 3D 섀도 맵이나 물체 사이의 정확한 그림자 계산은 아니다. 창 크기가 바뀌면 프레임버퍼도 재생성한다. 생성 실패 시 콘솔에 알리고 후처리 없이 직접 그리는 경로로 전환한다.

물의 반짝임은 물결 변화로 계산한 근사 광원 반응이다. 주변 건물·나무를 실제 수면에 반사하는 렌더링 패스는 포함하지 않는다.

### 야생 짐승

사슴 5마리, 토끼 5마리, 멧돼지 5마리, 총 15마리를 숲과 확장 지역에 배치했다. 종별 몸통·다리·뿔·귀·엄니를 구분하고 이동에 맞춰 다리를 움직인다. 주변을 배회하다 플레이어가 가까워지면 피하고, 활동 범위를 벗어나면 서식지 방향으로 돌아온다. 충돌한 방향 대신 다른 방향을 시도한다.

비전투 생태 표현이므로 공격·피해·사냥·전리품은 없다. 대화·지도·선택 중에는 짐승 이동을 멈추며 재시작 시 처음 위치로 돌아온다. 지도 확대 화면에는 주민과 짐승 위치도 표시한다.

## 이번에 포함하지 않는 기능

튜토리얼 지역 자체에는 전투, 피해, 회복·부활 실행, 인벤토리, 저장/불러오기, 주민 자율 행동, 사운드, 월드 스트리밍을 포함하지 않는다. 회복·부활의 대가라는 본편 기준은 유지하며 약초사 대화로 소개하지만 구체적인 비용 규칙은 임의로 만들지 않았다. L로 진입하는 별도 [첫 사냥 지역](FIRST_LEVEL.md)에서 공격·피해·전리품·경험치와 스탯 증가를 확인할 수 있다.

## 실행 환경과 사용자 확인 항목

기존 SimpleGame.sln에서 빌드한다. OpenGL 3.3 compatibility context와 Windows 맑은 고딕을 사용한다. 셰이더는 빌드 출력의 Shaders 폴더에 복사되도록 설정했다. 기존 freeglut.dll·glew32.dll은 빌드 플랫폼(Win32/x64)에 맞는 출력 폴더의 파일을 사용한다. DLL은 기존 로컬 환경에 있으며 저장소에서 새로 받는 경우 별도 준비가 필요하다.

기본 창은 1280 × 800, 최소 창 크기는 1100 × 700이다.

1. 빌드가 성공하고 한국어 UI·마을·숲·호수가 표시되는지 확인한다.
2. 장애물 없는 곳에서 WASD와 네 대각선 이동의 화면상 속도가 같은지 확인한다. 카메라가 플레이어를 따라오므로 지면 대비 이동을 비교한다. 키를 놓았을 때 정지와 창 전환 후 이동 멈춤도 확인한다.
3. 건물·나무·호수 충돌과 필수 목적지 접근 가능 여부를 확인한다.
4. 순서대로 퀘스트를 진행하고, 먼저 방문한 후속 단서가 단계를 건너뛰게 하지 않는지 확인한다.
5. E를 길게 누를 때 대화가 모두 넘어가지 않는지, 대화 중 이동하지 않는지 확인한다.
6. 각각의 선택을 한 번씩 플레이해 물빛·선택 이력·주민 대사가 일치하는지 확인한다.
7. 귀환 완료, 자유 탐험, Esc/R 재시작, 지도 토글과 창 크기 변경을 확인한다.
8. 완료 시간과 읽기·이동 체감을 기록한다. 제작 중 빌드나 실제 플레이 시간 측정은 수행하지 않았다.
9. P를 눌러 블룸·색 보정·가장자리 차이를 비교하고 UI는 선명하게 유지되는지 확인한다.
10. WASD 네 방향의 스프라이트와 걷기·정지 전환, 캐릭터가 장애물에 막혔을 때 정지 포즈를 확인한다.
11. 카메라 이동 시 지면 무늬가 움직이지 않는지, 접촉 그림자·불꽃·포말과 물결을 확인한다.
12. 확장 맵에서 주민 38명, 동물 15마리와 농가·야영지·폐허를 찾아본다. 동물의 배회·회피·호수/건물/나무 충돌을 확인한다.
13. 창 크기를 바꾼 뒤 후처리 화면이 올바르게 다시 그려지고 미니맵이 전체 304×264 범위를 표시하는지 확인한다.
14. 작은 집에서도 문·창문·덧문이 겹치지 않는지, 벽과 지붕 무늬의 방향, 굴뚝 연결과 연기를 확인한다.
15. 숲에서 잎의 겹침·흔들림·플레이어 가림과 프레임 속도를 확인한다. 호수에서는 물결·반짝임·포말·갈대를 확인한다.
