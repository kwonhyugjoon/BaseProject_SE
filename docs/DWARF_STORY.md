# 드워프 이야기 · 돌에 새긴 귀환 약속

2단계 기준일: 2026-11-03 (LEC08).

## 진행

지도 기록자는 드워프를 소탕하는 사람이 아니라 기록을 옮기며 닫힌 길의 이유를 알아가는 여행자다. 호수의 두 선택은 모두 유지되며 드워프 의뢰를 막지 않는다.

1. 갈대여울의 마지막 보고를 마치고 돌등성이 전초지의 이정표를 E로 조사한다. 이전의 세 이정표 조사를 모두 마치면 일지가 파수꾼 토르빅을 안내한다. 다른 이정표가 남아 있어도 토르빅을 직접 만나 의뢰를 시작할 수 있다.
2. 중앙 이정표 옆 (55,41)의 토르빅과 E로 대화한다. 마지막 대화 페이지를 닫으면 폐광 작업 기록 의뢰가 시작된다.
3. 돌등성이 동쪽 출입구 (73,57)에서 깊은돌 폐광길로 이동한다. 중앙 기록대 (49,41)를 E로 조사하고 마지막 페이지까지 읽으면 도시 진입 자격을 얻는다. 몬스터 처치 수를 입장 조건으로 삼지 않는다.
4. 폐광 (73,57)의 문에서 깊은돌 도시 앞마당으로 들어간다. 기록관 브린 (49,41)에게 보고하면 두 선택을 제시한다.
5. 1 또는 2로 결정한다. 대장장이 도르나 (57,43), 브린과 토르빅이 결과에 반응한다. 일지에 선택과 이유가 남고 의뢰 보상 75XP는 한 번만 받는다. 현재 체력은 회복하지 않는다.

깊은돌 폐광길은 숲으로 둘러싸인 산길의 폐광 작업장이다. 도시 앞마당에는 석조 문, 기록관·대장장이와 불꽃이 있는 작업장이 있다. 도시 전체의 주거 공간이나 지하 미로를 완성한 범위는 아니다.

## 발견하는 사실과 선택

수호체는 원래 광부의 귀환 등불을 읽던 장치였다. 과도한 채굴 뒤 낯선 울림이 귀환 신호를 흉내 내기 시작했고 도시는 채굴과 지름길을 멈췄다. 이 기록은 호수의 표식과 닮았지만, 미지의 존재와 봉인 전체의 기원을 단정하지 않는다.

| 선택 | 실제 세계 반영 | 남는 대가 |
|---|---|---|
| 1 · 감시 아래 교역 재개 | 솔바람 분지 ↔ 깊은돌 폐광길의 양방향 지름길 개방, 주민 대사·도시 분위기·성향·소문 변경 | 감시와 수리를 함께 책임진다는 약속 |
| 2 · 봉인 유지 | 지름길은 계속 닫힘, 돌등성이를 거치는 기존 산길은 유지, 주민 대사·도시 상태 변경 | 교역과 이동이 먼 산길을 거침 |

회복·부활의 비용이나 PvP 약탈 규칙을 새로 정하지 않았다. 두 선택 모두 도시 왕래와 이후 모험을 유지한다. 현재 드워프 선택은 다음 합류 이야기에서 참조할 수 있는 완료 이력이며 용·해안·2막과 결말은 후속 단계다.

## 조작과 보존

- E / Space: 대화·기록의 다음 페이지. 마지막 페이지에서 실제 진행을 기록한다.
- 1 / 2: 브린의 선택 화면에서만 확정. 다른 숫자는 무시한다.
- J: 목표·단서·선택·이동 경로. 닫힌 길은 경로 안내에서 제외한다.
- M: 출입구, 봉인 표시, 목표 주민·기록대를 확인한다.
- I: 야외 재료·광맥 광석·수호체 부품과 기존 성장·전리품을 확인한다.

지역 대화와 선택 중 이동·적 AI·전투를 정지한다. 일지를 겹쳐 열지 않으며 대화 시작과 종료 시 잡고 있던 이동·공격 입력을 비운다. 지역 이동과 원정 R 재시작은 의뢰·선택을 유지한다. R은 기존 개발용 성장·가방 초기화를 그대로 수행한다. 마을에서 튜토리얼을 처음부터 시작하거나 앱을 종료하면 이번 실행의 기록이 초기화된다. 디스크 세이브는 9단계 범위다.

## 몬스터와 전리품

| 지역 | 실제 구성 | 차별점 |
|---|---|---|
| 옛 교역로·메아리 숲길 | 도적, 궁수, 숲 늑대 | 인간의 근접/원거리 행동, 늑대의 예고 후 고정 방향 돌진 |
| 돌등성이 | 늑대, 광맥 갑충, 도적, 궁수 | 산길 야생 위협과 유적을 노리는 침입자 |
| 깊은돌 폐광길 | 광맥 갑충, 고장 난 석재 수호체 | 갑충은 평소 피해 3 경감·공격 예고 중 틈 노출, 수호체는 고정 지점에 느린 범위 타격 |
| 깊은돌 도시 앞마당 | 적 없음 | 평화 지역, 대화와 선택에 집중 |

몬스터는 살아 있는 드워프 주민과 구분한다. 위협을 피해 작업 기록만 조사해도 의뢰가 진행된다. 늑대는 방향을 고정한 뒤 약 0.45초 이내로 돌진하고, 수호체는 1.3초 예고 뒤 2.3단위 범위를 타격한다. 경로 충돌과 시야 검사를 적용한다.

기존 처치 경험치·동전·탐험 결정에 더해, 일반 적은 야외 재료, 갑충은 광맥 광석, 수호체는 부품을 떨어뜨린다. E로 실제 줍는 순간 가방에 반영하며 지역 이동으로 미획득 전리품은 제거된다. 활성 전투 지역은 16구역·48마리를 유지한다. 분지·안개 호숫가의 기존 임시 구성은 본편 고원·해안 제작 때 교체할 범위다.

도형 기반 몬스터·드워프·석조 문·기록대·전리품을 level-models-v2.mesh로 캐싱한다. 14종 모델을 최초 생성 후 파일에서 재로딩한다. 파일 버전은 2로 올렸으며 캐릭터 스프라이트 캐시는 그대로다. 불꽃은 기존 셰이더를 이용한다.

위 내용은 2단계 당시의 캐시 구성이다. 2026-11-07 기준 고원 추가 후에는 기존 모델을 포함한 21종을 level-models-v3.mesh로 저장·로드한다. [고원 이야기](DRAGON_STORY.md)를 따른다.

## 검증 범위와 사용자 확인

tests/RunTravelChecks.cmd는 게임 창 없이 일곱 독립 테스트를 실행한다. DwarfStoryTests는 두 분기·도시 입장 조건·양방향 지름길·진행 순서·중복 보상 방지·대화 중 정지·선택 보존·전리품·공격 회피·새 모델 파일 재로딩을 검사한다. RegionConnectivityTests는 7지역×32시드, 총 224개 생성 맵에서 연결성·중앙 통행·출입구·밀도와 평화 도시를 검사한다. QuestJournalTests에는 실제 게임 입력으로 지역 대화 시작·종료 시 이동·공격이 남지 않는 검사도 포함한다. 테스트 캐시는 임시 폴더를 사용한다. MSVC x64 /O2 /MD에서 일곱 테스트가 모두 통과했다. 로컬 원시 로그는 x64/JournalChecks/dwarf-story-results.txt에 보관하며 버전 관리 대상은 아니다.

실제 Visual Studio 게임 빌드·OpenGL 화면·한글 패널·새 모델의 인상·전투 감각·FPS는 사용자 확인 범위다. Release | x64에서 한 선택으로 의뢰를 끝내고 왕복한 뒤, 새 실행에서는 다른 선택을 골라 지름길과 주민 반응을 비교한다. 도시가 전투 없이 유지되고 숲의 외곽 귀환과 달리기가 유지되는지도 확인한다.
