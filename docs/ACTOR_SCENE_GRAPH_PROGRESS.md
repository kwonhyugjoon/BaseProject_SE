# Actor / SceneGraph 작업 상태

2026-09-21: 중단했던 구현과 정적 검토를 마무리했다. 빌드·실행 검증은 사용자 확인 전이다.

## 반영 내용

- 튜토리얼과 첫 레벨의 화면 객체를 지속되는 Actor 노드로 배치했다.
- SceneGraph에서 부모·자식 위치 전파, 표시/갱신 활성 상속, 레이어·깊이 정렬을 처리한다.
- 그림자·무기·체력 표시를 해당 객체의 자식으로 연결했다. UI는 별도 트리의 복합 HUD Actor로 관리한다.
- 순회 중 생성은 다음 업데이트부터 처리하고, 삭제는 순회 종료까지 지연한다.
- 적 사망·재등장, 전리품 획득, 튜토리얼 재시작과 사냥터 재생성에 노드 수명 처리를 연결했다.
- 전리품은 월드 좌표로 배치하며 게임 데이터를 먼저 제거한 뒤 Actor를 제거한다.

## 정적 검토

- 기존 코드와 이동·전투·AI 갱신 경로를 대조했다.
- 위치 참조와 콜백 인덱스 수명, 부모 이동, 자식 삭제 및 렌더 레이어를 검토했다.
- Renderer 오프셋이 도형·모델·문자별로 한 번 적용되는 경로를 확인했다.
- 월드 → 후처리 → UI 렌더 순서와 기존 임시 렌더 객체 목록 제거를 확인했다.
- 새 소스의 프로젝트 등록, XML 구조, 코드 서식 및 diff 공백을 확인했다.
- 독립 테스트 소스를 작성했으나 빌드·실행하지 않았다. 게임도 빌드·실행하지 않았다.

## 사용자 실행 확인

Visual Studio에서 프로젝트를 다시 로드한 뒤 빌드한다. 튜토리얼 이동·대화·호수 선택·재시작, 사냥터 진입·전투·전리품 획득·적 재등장·귀환을 확인한다. 그림자와 UI 표시, 숲 이동 중 프레임도 확인한다.

지형 충돌은 기존 고정 격자를 유지한다. 노드 이동만으로 맵 충돌 구조를 편집하는 기능은 포함하지 않았다. 게임 데이터가 참조하는 노드를 삭제할 때는 해당 데이터도 함께 정리해야 한다.

구조와 테스트 실행 방법은 [Actor와 Scene Graph](ACTOR_SCENE_GRAPH.md)를 따른다. 커밋·푸시는 수행하지 않았다.
