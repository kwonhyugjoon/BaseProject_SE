# 지역별 몬스터 테마 계획

2026-10-31 기준: 지역 이야기와 맞는 몬스터 구성을 앞으로 각 지역 제작의 완료 조건에 포함한다. 기존 10단계 안에 흡수하며 별도 요청 단계를 늘리지 않는다.

초기 공통 슬라임·도적·궁수·사제는 전투 시스템을 시험하는 구성이었다. 2026-11-03 2단계에서 교역길·돌등성이·폐광, 2026-11-07 3단계에서 고원의 테마를 구현했다. 분지·안개 호숫가의 공통 구성과 해안·최종 지역은 후속 범위다. 이름이나 색만 바꾼 동일한 몬스터로 모든 지역을 채우는 것을 완성 상태로 취급하지 않는다.

| 지역과 제작 단계 | 이야기와 대표 위협의 방향 | 구분할 전투·표현·보상 |
|---|---|---|
| 교역길·숲길 / 2단계의 연결 지역 정리 | 교역로를 점거한 도적, 정찰병·궁수와 야생 위협. 습지의 슬라임과 유적을 좇는 사제는 등장 이유가 있는 곳에 한정 | 길목 매복·순찰, 인간과 야생 생물의 실루엣·행동 차이, 약탈품과 야외 재료 |
| 드워프·폐광 / 2단계 | 폐광 생물, 고장 난 기계·석재 수호체, 유적을 노리는 침입자 | 좁은 곳의 무거운 타격과 돌진·정비 흔적, 석재·금속 형태, 광석·부품 등 전리품 |
| 고원·용의 흔적 / 3단계 | 용의 영향이 남은 비늘 생물, 바람·열과 연관된 위협 | 이동 예고·돌진·영역 공격 등 차이, 비늘·바람·열의 표현과 해당 지역 재료 |
| 해안·물 아래 유적 / 4단계 | 조수에 적응한 생물, 꿈과 심해의 영향이 나타나는 존재 | 물가·조수·기이한 예고 행동, 수면과 다른 실루엣·색·효과, 젖은 기록·심해 재료 |
| 세계의 경계 / 7단계 | 앞선 선택과 교류 상태를 반영한 존재와 수호 장치 | 이전 지식을 활용하는 조합·대응, 싸움 외의 접근 가능성, 최종 이야기와 맞는 보상 |

세부 종족명·수치·정확한 보상은 해당 단계의 구현 때 정한다. 드워프 주민, 용, 미지의 존재 전체를 적대 몬스터로 고정하지 않는다. 대화·시험·이해라는 기존 이야기 방향을 유지한다. 일반 마을의 사제·순례자와 적대 무리를 동일시하지 않는다.

2단계 실제 구현은 [드워프 이야기](DWARF_STORY.md)를 따른다. 교역길은 도적·궁수·돌진하는 늑대, 돌등성이는 늑대·갑충·침입자, 폐광은 껍질 방어를 가진 갑충과 예고 범위 공격을 하는 수호체, 도시는 평화 지역으로 구분했다. 야외 재료·광석·부품의 모델과 가방 수량도 구분하며 모델 캐시는 v2로 갱신했다.

3단계는 [고원 이야기](DRAGON_STORY.md)를 따른다. 능선 비늘도마뱀의 방어와 방향 고정 돌진, 바람 정령의 후퇴·예고 위치 돌풍·밀쳐냄, 열맥 불씨의 지속 장판을 구분한다. 각 전리품은 능선 비늘·바람 결정·열맥 잔재이며 모델 캐시는 v3다. 고룡은 적 몬스터가 아니며 쉼터에는 일반 적을 배치하지 않는다.

각 지역 완료 검토에 다음을 포함한다.

- 왜 이 위협이 이 장소에 있는지 NPC·기록·배치에서 이해할 수 있는가.
- 대표 위협의 형태와 애니메이션, 행동 패턴·공격 예고가 다른 지역과 구분되는가.
- 길을 나무로 막는 대신 위험한 조우로 표현하며, 도착 위치와 통행 경로는 보장되는가.
- 전리품·강도·배치 밀도가 지역과 진행에 맞는가.
- 도형/스프라이트 기반과 파일 모델 캐시, Actor/SceneGraph 관리 기준을 지키는가.
- 독립 검사 결과와 실제 화면·전투 감각·FPS 확인을 구분했는가.

6단계에서 아이템·보상 균형을 묶어 조정하고, 10단계에서 지역 테마가 겉모습·행동·이야기 모두에 반영됐는지 통합 확인한다.
