# 공통 퀘스트 기록과 여행 일지

1단계 기준일: 2026-10-31 (LEC07).

## 공통 기록

게임이 QuestJournal 하나를 소유하고, 마을과 FirstLevel의 모든 전투 지역이 같은 객체를 참조한다. 마을의 퀘스트 단계·호수 선택은 이 객체의 읽기 전용 참조이며, 지역별 사본을 따로 만들지 않는다.

- 튜토리얼 단계는 해당 대화의 마지막 페이지를 닫을 때 진행한다. 현재 단계와 맞지 않는 완료 요청, 중복 완료, 제단 선택 없는 완료를 거부한다.
- 표석·지도 조각·미라의 꿈 같은 단서는 실제 완료한 단계까지만 표시한다. 후속 단서를 먼저 방문해도 이전 목표가 완료되지 않는다.
- 호수의 선택은 제단 단계에서 한 번만 기록한다. 지역 왕복·이정표 조사·원정 재시작으로 덮어쓰지 않는다.
- 방문한 지역, 조사한 이정표, 실제 오간 지역 연결을 기록한다. 같은 길을 되돌아오거나 같은 이정표를 다시 조사해도 기록을 중복 추가하지 않는다.
- 이동 경로 기록은 WorldTravel의 실제 연결 목록을 확인한다. 연결되지 않은 두 지역을 직접 오갔다고 기록하지 않는다.

## 조작과 UI

| 키 | 기능 |
|---|---|
| J | 현재 지역에서 여행 일지 열기·닫기 |
| 1 / 2 / 3 | 목표 / 단서·선택 / 탐험 기록 탭 |
| A / D | 이전·다음 쪽 |
| Esc | 열린 일지를 닫고 게임으로 복귀 |
| E | 기존 대화·조사·지역 이동. 세 야외 지역의 이정표도 조사 |
| Shift (유지) | 마을·모든 전투 지역에서 걷기의 2배 속도로 달리기 |

일지는 각 지역의 기존 HUD Actor가 그리는 공통 패널이다. 글자나 행별로 임시 렌더 객체를 만들지 않는다. 창 너비에 맞춰 긴 글을 나누고, 높이에 맞춰 페이지를 나눈다.

대화·제단 선택·지도·가방·일시정지·원정 실패 화면 위에는 일지를 겹쳐 열지 않는다. 일지가 열리면 주민·동물·적의 이동과 전투를 멈추고 잡고 있던 입력을 비운다. 일지의 1/2가 제단 선택으로 전달되거나, A/D가 플레이어 이동으로 전달되지 않는다. Esc는 일지만 닫는다.

## 목표와 다음 목적지

튜토리얼 진행 순서는 유지한다. 다른 지역으로 먼저 갔다면 일지에서 갈대여울로 돌아오는 경로와 아직 남은 튜토리얼 목표를 확인할 수 있다.

촌장에게 마지막 보고를 마친 뒤에는 **옛길의 이정표** 기록이 이어진다.

1. 솔바람 분지의 이정표 조사.
2. 돌등성이 전초지의 드워프 표식 기록.
3. 안개 호숫가의 물결 표식 기록.

위 순서는 기본 안내 순서다. 다른 순서로 조사해도 해당 기록이 남으며, 이미 기록한 곳을 다시 조사하도록 요구하지 않는다. 방문만으로 조사가 완료되지는 않으며 실제 이정표 가까이에서 E를 눌러야 한다. 세 지역의 조사를 마치면 돌등성이의 토르빅을 안내한다. 드워프 의뢰를 시작하면 폐광 기록 → 도시 보고 → 선택을 우선 안내하며 완료 후 남은 이정표로 돌아간다. [드워프 이야기](DWARF_STORY.md)의 별도 진행·선택을 공유 일지에 기록한다. 용·심해 존재의 본편 퀘스트는 후속 단계다.

목표 탭은 현재 구현된 지역 연결 그래프에서 다음 목적지까지의 최단 이동 경로를 보여준다. 탐험 기록 탭은 실제 방문·이동한 것만 보여준다. 안내된 경로와 이미 탐험한 기록은 구분한다.

전투 지역 HUD에도 동일한 퀘스트 목표와 다음 출입구를 표시한다. 지도에서 노란 점은 다음 목표로 향하는 출구 또는 현재 조사할 이정표, 청록색은 나머지 출구, 황토색은 다른 이정표다. 기존 공격·경험치·가방 UI는 유지한다.

## 유지와 초기화

| 상황 | 일지·퀘스트·선택 |
|---|---|
| 지역 이동과 재진입 | 유지 |
| 숲·연결로 외곽에서 길을 잃고 귀환 | 유지 |
| 전투 지역에서 R로 원정 재시작 | 유지. 기존 전투 성장·전리품 초기화 규칙은 유지 |
| 마을 일시정지에서 R로 튜토리얼 처음부터 | 튜토리얼과 일지 초기화 |
| 앱 종료 후 새 실행 | 초기화 |

드워프의 의뢰 단계·기록·선택도 같은 객체에 보존하며, 실제로 닫힌 도시 문과 지름길은 다음 경로 탐색에서 제외한다. 드워프 대화·선택 중 일지를 겹쳐 열지 않는다.

현재 실행의 메모리 기록이며 디스크 저장을 추가하지 않았다. 저장·불러오기는 개발 계획 9단계의 범위다. 회복·부활의 대가나 본편의 결말 조건을 이번 단계에서 정하지 않는다.

## 검증과 사용자 확인

게임 창 없이 tests/RunTravelChecks.cmd로 독립 테스트를 컴파일·실행한다. 기존 지역 이동·160개 맵 연결성·전투·주민 검사와 함께 QuestJournalTests 및 SprintTests를 실행한다. MSVC x64 /O2 /MD에서 달리기·축소 맵·열린 교역길 변경 뒤 SprintTests를 포함한 여섯 테스트를 모두 통과했다. 실제 게임 실행 파일의 Visual Studio 빌드나 OpenGL 화면 검증을 뜻하지 않는다. 로컬 일지 원시 로그는 x64/JournalChecks/results.txt, 달리기·배치·열린 길 검사 로그는 x64/JournalChecks/sprint-layout-results.txt에 저장했으며 버전 관리 대상은 아니다.

QuestJournalTests는 실제 입력·대화 완료 처리로 다음을 확인한다.

- 잘못된 순서의 단서·중복 단계·유효하지 않은 선택 거부.
- 두 호수 선택 각각의 보존과 단계별 단서 표시.
- 실제 지역 연결에 맞는 다음 목적지 경로와 중복 없는 왕복 기록.
- 이정표를 다른 순서로 조사해도 완료한 조사 보존.
- 일지 입력의 분리와 열린 일지에서 이동·전투·출구 상호작용 정지.
- 전투 원정 재시작·마을 왕복 후 기록 유지, 튜토리얼 재시작 시 초기화.

드워프 단계·선택·잠긴 경로 처리와 지역 대화 입력 차단을 포함해 일곱 독립 테스트를 통과했다. 세부 범위와 현재 로그는 [드워프 이야기](DWARF_STORY.md)에 기록한다.

실제 Visual Studio 게임 빌드·OpenGL 실행·한글 패널의 시각 배치·페이지 이동 감각·FPS는 별도 사용자 확인 항목이다.

사용자는 Release | x64에서 튜토리얼 대화 후 J를 열어 목표를 확인하고, 대화/제단 선택/지도/가방 중 J가 겹쳐 열리지 않는지 확인한다. 두 선택 중 하나로 보고를 마친 뒤 세 이정표를 순서와 다르게 조사해도 목표·단서가 이어지는지, 원정 R 및 마을 왕복 후 선택이 남는지 확인한다. 일지의 각 탭과 긴 글 페이지, 일지를 닫은 뒤 입력이 남지 않는지도 확인한다.
