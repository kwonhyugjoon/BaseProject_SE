# 요청 10회 기준 개발 계획

기준일: 2026-10-27. 지역 이동 구현을 출발점으로, **약 10회의 제작 요청으로 처음부터 결말·후일담까지 플레이할 수 있는 수업용 RPG 프로토타입**을 완성한다. C++/OpenGL, 쿼터뷰 2.5D, 싱글플레이와 현재 도형 기반 표현을 유지한다.

## 단계별 작업 기준

- 한 요청은 기본적으로 한 단계다. 교수님의 별도 지시·강의 실습이 있으면 그것을 우선하고, 연관되는 단계에 흡수하거나 남은 단계를 조정한다. 강의 작업 때문에 단계를 자동으로 완료 처리하지 않는다.
- 기능은 코드와 설계 문서를 함께 갱신한다. 구현·독립 검사·실제 플레이 확인을 구분하고, 완료한 단계와 다음 단계를 이 문서에 남긴다.
- 빌드·게임 실행·화면과 FPS 확인은 기본적으로 사용자가 한다. 독립 검사에 빌드·실행이 필요한 예외는 먼저 이유를 설명한다.

## 10단계

| 단계 | 제작 내용 | 완료 기준 | 상태 |
|---|---|---|---|
| 1 | 공통 퀘스트 기록과 여행 일지 | 지역을 오가도 목표·단서·선택 이력이 이어지고 일지에서 다음 목적지를 확인 | 구현 완료 · 독립 검사 통과 / 사용자 플레이 확인 대기 |
| 2 | 드워프 지역의 첫 본편 이야기 | 돌등성이의 폐광·도시 이야기와 선택·연결로, 교역길/드워프 지역의 몬스터 테마·외형·행동·전리품 | 구현 완료 · 독립 검사 통과 / 사용자 플레이 확인 대기 |
| 3 | 고원과 용의 흔적 | 고원 경로·전설·고룡 접근 방식, 용·바람·열에 맞는 대표 몬스터의 외형·행동·전리품 | 대기 |
| 4 | 해안과 미지의 존재 | 꿈·수중 유적·접촉 선택과 호수의 이력, 조수·심해 테마 몬스터의 외형·행동·전리품 | 대기 |
| 5 | 두 지역의 진실을 연결하는 2막 | 세 지역 중 두 곳 완료로 합류 이야기 개방, NPC·길·소문에 선택 반영 | 대기 |
| 6 | 여행을 지탱하는 성장·아이템·치료 | 가방·장비·보상 정리, 합의한 회복/부활 대가 적용, 이동으로 무료 회복되지 않음 | 대기 |
| 7 | 세계의 경계 원정 | 최종 지역과 연결로·봉인의 목적·대가, 앞선 선택과 지역 테마에 맞는 위협 구성 | 대기 |
| 8 | 결말과 계속되는 여행 | 봉인 유지/개방/조건부 교류의 조건·결과, 결말 이후 탐험과 세계 반응 | 대기 |
| 9 | 저장·불러오기와 진행 복구 | 위치·성장·아이템·퀘스트·선택·지역 상태를 복원하고 통행 가능한 위치에서 재개 | 대기 |
| 10 | 전체 통합과 완주 점검 | 서막~결말 진행·입력·전투·테마 구분·균형·가독성·성능과 사용자 플레이 결과 확인 | 대기 |

회복·부활의 구체적인 비용과 최종 결말 해금 수치처럼 아직 정하지 않은 핵심 규칙은 해당 단계에서 결정한다. 문서상의 계획을 이미 구현한 기능으로 취급하지 않는다. 작업량이나 강의 요구가 달라지면 큰 목표 10개를 유지하면서 세부 내용을 조정한다.

지역별 몬스터 테마는 각 지역을 제작할 때 외형·행동·등장 이유·전리품까지 구현하는 완료 조건으로 포함한다. 단계 수를 늘리지 않고 2·3·4·7·10단계에 반영한다. [몬스터 테마 계획](MONSTER_THEMES.md)을 따른다.

## 현재 출발점

- `LEC04`, 2026-10-13: Actor/SceneGraph, 주민·맵 확장, 로컬 모니터와 CPU 성능 개선.
- `LEC05`, 2026-10-20: 지도 기록자의 동기, 표석·호수·옛 교역로·도적을 잇는 초반 이야기.
- `LEC06`, 2026-10-27 기준 작업: 배치된 문에서 E로 이동, 출구 수와 목적지가 다른 두 던전, 일반 지역·던전의 외곽 귀환.
- `LEC07`, 1단계, 2026-10-31 기준 작업: 공통 QuestJournal, J 일지, 단계별 단서·호수 선택·방문/경로 기록과 이정표 목표 안내, Shift 유지 시 2배 달리기, 맵 축소·중앙 배치·장애물 없는 교역길. [일지 구현과 검증](QUEST_JOURNAL.md)을 따른다.
- `LEC08`, 2단계, 2026-11-03 기준 작업: 토르빅의 의뢰·폐광 기록·도시의 선택, 선택별 양방향 지름길과 주민 반응, 교역길/폐광 몬스터와 전리품·모델 캐시. [드워프 이야기](DWARF_STORY.md)를 따른다.
- 다음 제작 요청은 **3단계: 고원과 용의 흔적**부터 진행한다.

현재 지역 연결과 확인 항목은 [지역 이동](WORLD_TRAVEL.md), 이야기의 전체 골격은 [게임 개발 기준](GAME_DESIGN.md)을 따른다. 드워프 첫 이야기는 구현했으며, 고원·해안·2막과 결말은 후속 단계다. 실제 화면과 플레이 확인은 사용자 확인 대기 상태다.
